📦 极简封装函数

一行代码为任意元素添加「鼠标悬停提示框」功能
// 💡 封装函数（复制即用，超简单） function addHoverAlert(element, message) { element.addEventListener('mouseenter', function() { alert(message || '🐱 鼠标放在了 div 上！'); }); }

✨ 用法示例：
addHoverAlert( document.getElementById('myDiv'), '自定义提示内容' );
➕ 第二个参数可选，默认提示 “🐱 鼠标放在了 div 上！”

📌 超简单封装原理
• 函数 addHoverAlert(element, message) 内部使用 mouseenter 事件（最稳定，无冒泡干扰）。
• 只要传入 DOM 元素和可选提示文字，就能实现鼠标移入弹 alert。
• 支持任意 HTML 元素（div、按钮、图片等），可复用，可批量调用。
• 完全原生 JavaScript，无任何依赖，兼容所有现代浏览器。
⚡ 轻量 · 易封装 · 一个函数搞定所有悬停提示需求
