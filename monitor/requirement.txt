### 4.10 数据对比视图

**侧边栏控件**（高度约450px，可滚动）：

| 控件 | 类型 | 说明 |
|------|------|------|
| Casename | 下拉 | 选择要对比的case |
| 对比模式 | 下拉 | 对比全部rule / 指定rule |
| 搜索rule | 输入框 | 过滤rule列表 |
| 日期1 | 下拉 | 基准日期 |
| 日期2 | 下拉 | 对比日期 |
| 误差模式 | 下拉 | 绝对值 / 百分比 |
| 对比维度 | 下拉 | 全部 / runtime / memory |
| runtime误差范围 | 数字输入 | 默认0 |
| memory误差范围 | 数字输入 | 默认0 |
| 确认对比 | 按钮 | 青色，执行对比 |
| 导出结果 | 按钮 | 边框样式，导出CSV |

**中央内容区**：

1. **统计卡片区**（Grid 2x3）：
   - runtime/memory 增加rule（悬停显示前十）
   - runtime/memory 减少rule（悬停显示前十）
   - 平均变化率
   - 最大增加（悬停显示前十）
   - 最大减少（悬停显示前十）

2. **对比结果表格**：
   - 列：rule、日期1值、日期2值、绝对差值、百分比变化、是否超差
   - 顶部：筛选输入框（按rule名称模糊搜索）
   - 超差行：背景色`rgba(239,68,68,0.1)`
