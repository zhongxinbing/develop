设计一个优秀的HTML布局，核心是理解 **“结构与样式分离”** 和 **“响应式适配”**。下面为你梳理一套清晰的设计思路和实战方案。

### 1. 核心设计原则

在动手写代码前，建议遵循这4个原则：

-   **语义化**：使用 `<header>`、`<nav>`、`<main>`、`<aside>`、`<footer>` 等标签，而不是全用 `<div>`。这对SEO和代码可读性很重要。
-   **移动优先**：先为手机屏幕设计布局（通常默认单列），再通过媒体查询为平板、桌面增加多栏布局。这能保证在所有设备上都有良好体验。
-   **弹性盒子**：利用 Flexbox 或 Grid 进行精准布局，而不是依赖`float`或`table`。Flexbox适合一维排列（如导航栏），Grid适合二维复杂网格。
-   **可维护性**：使用CSS自定义属性（变量）统一管理颜色、间距，让后期修改更轻松。

### 2. 经典布局：上-下结构 + 两栏内容区

### 3. 进阶布局方案：CSS Grid “圣杯布局”

如果希望更精确地控制二维空间，可以使用 CSS Grid。下面是更现代、代码更简洁的“圣杯布局”（Header + 双栏 + Footer）。

```css
/* 核心 Grid 布局代码（可直接替换上面示例的 .main-grid 部分） */
.grid-layout {
    display: grid;
    grid-template-areas: 
        "header header"
        "sidebar main"
        "footer footer";
    grid-template-columns: 260px 1fr;  /* 侧边栏固定260px，主内容自适应 */
    gap: 0;
}

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }

/* 移动端适配：将grid改为单列 */
@media (max-width: 768px) {
    .grid-layout {
        grid-template-areas: 
            "header"
            "sidebar"
            "main"
            "footer";
        grid-template-columns: 1fr;
    }
}
```

### 4. 布局设计避坑指南

| 常见问题 | 正确做法 |
| :--- | :--- |
| 滥用 `position: absolute` 做整体布局 | 优先使用 Flexbox 或 Grid 控制文档流。定位用于局部微调。 |
| 忘记设置 `box-sizing: border-box` | 全局设置，让 `width` 包含内边距和边框，避免宽度计算混乱。 |
| 移动端布局崩坏 | 使用 `<meta name="viewport">` + 媒体查询，测试手机、平板断点。 |
| 内容宽度过大导致横向滚动 | 给根容器加 `overflow-x: hidden`，图片使用 `max-width: 100%`。 |
| 缺少 `main`、`aside` 等标签 | 屏幕阅读器依赖语义标签，增强无障碍体验。 |

### 5. 设计流程总结

1.  **画结构图**：纸上或设计软件中标出 header、nav、main、aside、footer。
2.  **写HTML骨架**：先完成语义标签，不写样式。
3.  **移动端样式**：默认单列布局，填充间距和字体。
4.  **添加Flex/Grid**：利用媒体查询，在断点处（如 `min-width: 768px`）改为多栏。
5.  **微调细节**：调整边距、圆角、阴影，提升视觉层次。
