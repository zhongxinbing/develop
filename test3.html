📐 理解弹性盒子 (Flexbox)

Flexbox 是一维布局模型，非常适合导航栏、侧边栏+内容区这类组件。只需在父容器设置 display: flex，子项就可以灵活排列、换行。

📌 内容占位区 | 展示设计思路

配合 flex-wrap 和 media queries，布局在不同屏幕下自动适配，移动端切换为垂直排列，桌面端恢复双栏。

📌 CSS Grid 进阶选择

Grid 更适合二维复杂布局（如作品集、卡片墙）。但经典的上-下+双栏结构，Flexbox 已经足够优雅。根据项目复杂度选择合适工具。

✅ 设计小贴士：始终为容器设置 max-width 和 margin: 0 auto 保证大屏幕居中，避免内容过度拉伸。
